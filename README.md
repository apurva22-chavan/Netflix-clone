# 🎬 Netflix Clone

A responsive Netflix-inspired web application built using HTML, CSS, and JavaScript. The project recreates the look and feel of the Netflix landing page with a modern user interface, responsive design, and interactive components.

---

## 📖 Overview

The Netflix Clone is a front-end web development project that replicates the user interface of the Netflix homepage. It focuses on responsive web design, clean layouts, and an engaging user experience while demonstrating core front-end development concepts.

This project was developed to strengthen HTML, CSS, and JavaScript skills and gain hands-on experience in building real-world web interfaces.

---

## 🎯 Objectives

- Recreate the Netflix landing page.
- Build a responsive and modern user interface.
- Practice front-end web development.
- Improve UI/UX design skills.
- Learn responsive layouts using HTML and CSS.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/apurva22-chavan/Netflix-clone.git
```

Navigate to the project folder:

```bash
cd Netflix-clone
```

Run the project:

- Open `index.html` in your browser

or

- Use **Live Server** in Visual Studio Code.
